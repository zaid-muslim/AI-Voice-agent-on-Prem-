Model & Backend Selection

Language model (LLM)

Switching restarts the shared vLLM process — NOT instant. Expect a real outage while the old model stops and the new one loads (15–60+ seconds; longer for a first-time download).

Text-to-speech (TTS)

Takes effect on the next call. No restart needed.

Speech-to-text (STT)

Takes effect for the next newly-spawned worker process. An already-warmed process keeps its current STT until recycled.

Latency by combination

Real per-turn measurements from actual calls, grouped by which LLM/STT/TTS combination was active. Averages update as you make more calls with each combination — this is measured data, not a benchmark claim. Switch combinations from the Models tab, make a few test calls, then compare here.
